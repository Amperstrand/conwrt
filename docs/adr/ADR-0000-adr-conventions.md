# ADR 0000: ADR conventions

- ADRs live in `docs/adr/`, numbered `ADR-NNNN-slug.md`.
- Sections: Status / Context / Decision / Consequences / Alternatives
  considered / Open questions.
- Statuses: proposed → accepted → superseded (by link). Decisions marked
  *reversible* must name the trigger that would reopen them.
- ADRs record tradeoffs and evidence, not just conclusions. Library claims cite
  the research dossier gathered 2026-10-12 (crates.io/GitHub API snapshot in
  the M0 research notes; re-verify before pinning versions).
